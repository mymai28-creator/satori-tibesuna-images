# 悟りのチベスナ ｜ 公開画像の置き場

Instagramの自動投稿（Content Publishing API）へ渡すための、画像の公開URL置き場です。
Instagram APIはローカル画像を受け取らないため、投稿する画像だけをここへ置き、そのURLをAPIに渡します。

- 公開URLの形： `https://mymai28-creator.github.io/satori-tibesuna-images/images/〈ファイル名〉`
- 置くのは **Instagramに出す画像だけ**。下書き・ボツは置きません
- アップロードは `projects/チベスナプロジェクト/scripts/画像を公開する.mjs`（メイン作業場）から行います

画像の著作・キャラクター設定は「悟りのチベスナ」に帰属します。
